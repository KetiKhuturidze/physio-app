Claude Code — რა არის და როგორ მუშაობს

Claude Code არის AI assistant რომელიც ტერმინალიდან მუშაობს. შენ ლაპარაკობ მასთან, ის კითხულობს შენს კოდს, წერს ახალ კოდს, ასწორებს შეცდომებს და მართავს workflow-ს. ის იცის React Native, Expo, Supabase, TypeScript — შენ არ გჭირდება ზეპირად ეს ყველაფერი.

✅ ასე მუშაობს კარგად

"დავიწყოთ FE-001 task"
"BE-004 hook-ი დავწეროთ"
"ეს error რას ნიშნავს?"
"booking flow გავტესტოთ"

❌ ასე არ მუშაობს კარგად

"გააკეთე app"
"კოდი არ მუშაობს"
"login screen-ი სჭირდება"
"react native-ში ასე ხდება?"
💡

მთავარი პრინციპი: Claude Code-ს ეუბნები task ID-ს ან კონკრეტულ მოქმედებას. ის გადაწყვეტს "როგორ". შენი საქმეა task-ები დაადასტურო, შეამოწმო და workflow გაიაროს.

Slash Commands — სრული სია

Claude Code chat-ში აკრიფე /command — Enter-ი.

/start
პირველი გაშვება — project onboarding. ერთხელ გაუშვი. Claude ეკითხება background-ს, ახსნის tech stack-ს, task-ებს გადიხართ ერთად.
/phase
მიმდინარე სტატუსი — tasks progress + coverage gate. Phase 1: X/21 done · Coverage: 67% · Gate: ✓
/check
TypeScript + ESLint. სავალდებულო ყოველი build-ის შემდეგ. tsc --noEmit + eslint · zero warnings policy
/test
Jest tests + phase coverage gate შემოწმება. Coverage: statements, branches, functions, lines — lowest of four
/e2e
Maestro E2E tests — სრული user journey-ები Simulator-ზე. Phase 1: 6 critical flows · Simulator must be running
/coverage
Detailed coverage report vs current phase gate. Per-file breakdown · shows lowest coverage files
/new-task
ახალი task-ის შექმნა structured format-ში. /new-task phase1 fe "ReviewCard component"
/update-skill
Bug fix-ის შემდეგ skill file-ის განახლება. /update-skill supabase "RLS doesn't block service role"
/memory-save
სესიის ბოლოს — session notes → memory vault. ყოველთვის გაუშვი. memory/sessions/YYYY-MM-DD.md + INDEX.md update
🎯

Daily routine: /phase → task-ი → build → /check → /test → /e2e → repeat
